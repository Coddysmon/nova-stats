# Статистика партий Nova

На [странице статистики](https://coddysmon.github.io/TournamentModPack/stats.html) можно сравнивать развитие игроков, выборы политик, религий и технологий. На [карте партии](https://coddysmon.github.io/TournamentModPack/replay.html) видно, как по ходам менялись города, границы и ресурсы.

Здесь публикуются данные завершённых сетевых партий Nova, зачтённых в статистику. В них видны ники участников. Игровой чат в карты партий не входит.

- `index.json` — список партий.
- `m/` — показатели по ходам.
- `choices.json` — выборы игроков.
- `replay/` — карты партий.

[О моде и установка](https://coddysmon.github.io/TournamentModPack/)
