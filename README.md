# nova-stats

Сгенерированные данные статистики сетевых партий модпака Nova для страницы
«Статистика» сайта (https://coddysmon.github.io/TournamentModPack/stats.html).

**Руками здесь ничего не правится.** Содержимое каждые 10 минут перезаписывается
выгрузкой со служебного сервера одним коммитом (`push --force`), история не хранится.

- `index.json` — список засчитанных сетевых партий без рядов по ходам
  (`{schema, generated, matches:[...]}`);
- `m/<ключ партии>/<REPLAYDATASET_...>.json` — партия с одним рядом по ходам.

Что публикуется: только сетевые партии, подтверждённые журналами не меньше двух
участников и записью об исходе. Одиночные партии не публикуются. Показываются ники
и имена профилей; номера Steam и ключи игроков не публикуются.

Nova match statistics (generated). Do not edit: the content is overwritten by an
automated export every 10 minutes.
